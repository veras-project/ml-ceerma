# Processamento de Dados - ML CEERMA

Este repositório contém o pipeline de tratamento, limpeza e estruturação de dados para os projetos de Machine Learning do CEERMA [projeto ventoinha mesa de vibração]. 

O objetivo principal desta base de código é garantir que os dados brutos sejam processados de forma reprodutível, documentada e pronta para a fase de modelagem preditiva.
